## 🔒 Owner-Only Admin Security

To keep customer data, order addresses, pricing controls, and daily revenue private:
- **Factory Direct Model (No Hourly Slots)**: Customers can order 24 hours a day, 7 days a week. Every fresh batch is prepared and delivered within 1 day (24 hours factory dispatch guarantee).
- **Public Customer App**: Customers can view real product photos, add to bag, place 24-hour factory orders, track progress, and message the store. All admin controls remain hidden.
- **Protected Owner Portal**: Accessible only by visiting `/admin` and entering the Owner Security PIN or Password.
